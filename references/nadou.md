# Nadou in Orca: established efficient route

Use only after loading the installed `orca-cli` skill and its version-matched browser reference. Resolve the CLI exactly as that skill directs. Do not guess a page ID, project URL, browser API or backend endpoint.

1. `orca tab list --json`: select the existing user-named project; pin its page ID and exact URL. Use `--expect-url` for guarded fill/click actions. Read a compact interactive snapshot or relevant DOM subtree, not the full canvas.
2. Resolve account assets by actual node labels, inspect character references once when needed, and record ordered asset IDs/types. Include the required role/voice mapping in prompts. Do not play every voice repeatedly when the user has already identified it.
3. Prefer copying a previously configured node. To set up a first template, Add Node → Video; select the appropriate generation mode and settings. Nadou's “多素材生成视频” quick start can add example media: remove those **references from the new node** before using it; do not delete the user's asset nodes. Choose from canvas and attach the account's actual images/audio. Check source-to-output connections and attachment order.
4. Model controls appear in a combined model/ratio/resolution/duration/count selector. Hidden radio inputs can reject clicks; use their visible labeled control. Duration may need Enter or blur to commit. Keep output count at the agreed number of variants per story; do not confuse it with number of different stories.
5. Copy configured node via normal UI: focus/select the node itself, not its prompt editor, then Ctrl+C and Ctrl+V. A paste can retain reference edges and generation settings but this must be checked once in the current UI. The new node should have no new generation job until explicitly submitted. Record its new ID.
6. Fill the new prompt in one file-backed operation. Before Generate, check the prompt belongs to the intended ID and exactly the account references remain. “sd素材校验中” is a submitted request undergoing validation, **not** permission to submit again. “生成中 …%” proves generation began. Record a returned video/completion state; do not press play to get a URL unless download/review was requested.
7. Reserve one review slot per task before cloning, then name and move the copy there immediately. On the tested Vue Flow UI, node label double-click opens a title input, and focused selected nodes support arrow-key movement; Shift+Arrow moved 20 canvas units in one observed version. Measure the actual delta once; do not assume that step in another version. Keep only the intended node selected. Verify saved positions, never merely set CSS transforms. Avoid background `requestAnimationFrame` loops: they may throttle or remain pending. Use short deterministic UI actions, or microtask flushes where appropriate, and ensure no prior action loop remains running.

## DOM observations, not stable API contracts

Previously observed: `.vue-flow__node` with `data-id`, `.nd-node-label-text`, `.nd-node-label-input`, `[contenteditable=true]`, `.multi-ref-media-slot`, `.preview-thumb.is-image`, `.preview-thumb.is-audio`, `.nd-node-loading[aria-label]`. Inspect current DOM once before using these selectors. They are UI elements, not private application stores. Prefer accessible names and current refs where they work.

Use reference thumbnail URLs only for identity checks; do not export cookies, auth headers or app secrets. Scope mutations to the bound page and task node. If refs go stale, refresh the relevant snapshot; if a DOM selector changes, stop that task and rediscover only that control. Do not run a full browser discovery cycle on every copied node.

Windows PowerShell can mangle nested quotes and `@e123` arguments. Quote refs or use `scripts/orca-bridge.cjs`, which calls the executable with an argument array. Read/write JSON with explicit UTF-8. The helper summarizes results; it does not itself clone, attach, lay out, or visually validate outputs.
